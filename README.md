# 手寫單據自動記帳

此工具在 Windows 本機讀取手寫單據照片，使用 Ollama 本機視覺模型辨識客戶、日期、數量與單價，並填入既有 Excel 表單。照片不會上傳到雲端。

## 使用方式

1. 執行 Slip2Excel 安裝檔。安裝程式會自動準備 Ollama 與預設辨識模型 `qwen2.5vl:7b`；請保持網路連線，並預留數 GB 的磁碟空間。
2. 從開始功能表或桌面捷徑開啟 Slip2Excel。
3. 第一次開啟時，依畫面指示進入「設定」，選擇「原始照片資料夾」與「空白 Excel 表單」，再按「儲存設定」。選擇空白表單時，客戶對照會自動建立。
4. 回到「讀取與寫入」，按「讀取照片資料夾」，等待進度條完成。
5. 確認結果；有問題的照片會顯示在「問題紀錄」，不會寫入。
6. 按「寫入 Excel」，完成檔會儲存在設定的「完成 Excel 儲存位置」。

辨識會在背景執行，視窗仍可移動與查看已完成的結果；如需停止，按「取消讀取」，系統會在目前照片完成後安全停止。

單據的第 1、2、3…列會對應到 Excel 固定列，因此不需辨識或輸入菜名。讀取失敗或讀到小計／總計列的照片不會寫入；若只有部分品項不完整，程式會略過該品項、記錄在「問題紀錄」，並寫入同張單據中其餘已確認的品項。

第一次寫入會由空白表單建立完成檔；之後使用相同「完成 Excel 儲存位置」時，程式會自動接續既有完成檔，不會遺失前一批資料。若本批資料的數量或單價目標格已有值，整批會停止且不會覆蓋任何資料。

同一客戶同一天應只有一張單據。程式只會寫入讀取順序中的第一張；第二張及之後的照片一律列入「問題紀錄」、不會寫入，並會顯示已保留的是哪一張照片。分批匯入時，若完成檔已有同一客戶同一天的資料，也會停止本批寫入。

## 開發環境

- Python 3.12+
- Windows
- Ollama
- 模型：`qwen2.5vl:7b`

開發時才需要執行 `python main.py` 或 `啟動記帳工具.bat`；一般使用者只需使用安裝後的 Slip2Excel 捷徑。

## 測試

開發修改後可執行：

```powershell
python -m py_compile main.py bookkeeping.py tests\test_bookkeeping.py
python -m unittest discover -s tests -v
```

測試會驗證日期與數字解析、重複資料處理、分批接續寫入、目標格防覆蓋、辨識問題清單，以及 Excel 寫入失敗時不覆蓋既有完成檔。每次匯出後程式也會回讀 Excel，逐一確認數量與單價均已實際寫入，才會顯示安全寫入完成。

`TrainPhoto/`、`config.json`、Excel 檔與 `logs/` 均為使用者本機資料，已排除在 Git 版本控制之外。
