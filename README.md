# 手寫單據自動記帳

此工具在 Windows 本機讀取手寫單據照片，使用 Ollama 本機視覺模型辨識客戶、日期、數量與單價，並填入既有 Excel 表單。照片不會上傳到雲端。

## 使用方式

1. 安裝 [Ollama](https://ollama.com/download)。
2. 在 PowerShell 執行：`ollama pull qwen2.5vl:7b`
3. 將空白 Excel 表單與照片資料夾放在工具資料夾中。
4. 執行 `啟動記帳工具.bat`，或執行 `python main.py`。
5. 在「設定」確認照片資料夾、空白表單、完成檔位置及模型名稱。
6. 在「讀取與寫入」按「讀取照片資料夾」，等待進度條完成後按「寫入 Excel」。

單據的第 1、2、3…列會對應到 Excel 固定列，因此不需辨識或輸入菜名。讀取失敗或品項不完整的照片會顯示在「辨識問題」頁籤；不完整品項不會寫入。

每次寫入都從空白表單重新建立完成檔。完全相同的重複照片只會寫入一次；若同一位置出現不同數量或單價，程式會停止並要求檢查照片。

## 開發環境

- Python 3.12+
- Windows
- Ollama
- 模型：`qwen2.5vl:7b`

`TrainPhoto/`、`config.json`、Excel 檔與 `logs/` 均為使用者本機資料，已排除在 Git 版本控制之外。
